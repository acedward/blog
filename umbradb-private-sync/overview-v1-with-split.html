Phone

Holds the wallet's keys. They never leave it.

  • Download: the same bytes for every phone.
  • Private fetch: an encrypted request, always the same size. The server answers without learning which entry was read.

The 36-byte and 8-byte incremental updates are the design. The proof of concept sends 257 B per new commitment and 40 B per new nullifier.

One coin's data, split by who needs it

The chain holds 256 bytes for each shielded coin, and the server computes its place in the Merkle tree. Every phone gets 36 of those bytes; the rest is fetched only by the coin's owner.
