What is measured

  • The table is laid out as a grid of 10-bit numbers. One query is one 32-bit number per column; the answer is one 32-bit number per row. The server multiplies every cell of the grid by the matching query number and sums along each row, with 32-bit wraparound.
  • A call carries several query vectors, and the grid is read once for all of them.
  • The table content here is random; the cost does not depend on the content. On the GPU three 10-bit numbers are packed into each 32-bit word.
  • The time covers sending the query vectors to the GPU, the multiplication, and reading the answers back. Building the table is not included.
  • The check recomputes a few rows in plain JavaScript and compares them with the GPU's answers. The same rows give the JavaScript time, projected to the whole table.
  • The wallet's side of the query (building the vectors, removing the mask) is not measured here.
